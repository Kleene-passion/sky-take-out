# Sky Take-Out (苍穹外卖)

A Spring Boot backend practice project completed during my Java Web development learning, based on the **Heima Programmer (黑马程序员) "苍穹外卖"** training project.

This repository documents my hands-on practice with Spring Boot backend development and related backend technologies.

## Tech Stack

- Java
- Spring Boot
- MyBatis
- MySQL
- Redis
- JWT
- Maven

## Project Overview

Sky Take-Out is a food delivery system that covers common backend development scenarios, including user authentication, category and product management, shopping cart operations, order processing, and related business logic.

During the development process, I practiced:

- Building RESTful backend APIs with Spring Boot
- Implementing database access and persistence with MyBatis and MySQL
- Implementing user authentication with JWT
- Using Redis for caching
- Developing and debugging common food delivery business logic
- API testing and front-end/back-end integration

## Learning Outcomes

Through this project, I gained practical experience with the development workflow of a Spring Boot backend application and strengthened my understanding of layered backend architecture, database operations, authentication, caching, API development, and system integration.

The commit history in this repository is retained as a record of my development and learning process.
